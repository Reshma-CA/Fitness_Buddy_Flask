## Project: FitnessBuddy – Workout Tracking Web Application

Developed FitnessBuddy, a web-based fitness tracking application using Python and Flask. Implemented user authentication with secure signup and login functionality using password hashing and session management with Flask-Login.

Built core features that allow authenticated users to create, view, update, and delete workout records, including tracking daily push-ups and workout comments. Designed protected routes to ensure only logged-in users can access and manage their data.

Implemented pagination for displaying workout history, flash messages for user feedback, and relational database models using Flask-SQLAlchemy. Followed MVC-style architecture with Blueprints to maintain clean and modular code structure. This project strengthened my understanding of backend development, authentication, CRUD operations, and database relationships.go to live: https://fitness-buddy-flask.onrender.com/
